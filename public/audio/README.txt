Thư mục lưu trữ nhạc nền mặc định cho PINK CHARACTER ARCHIVE:
- Đặt file nhạc của bạn tại: public/audio/background-music.mp3
- Định dạng khuyến nghị: MP3 (tỷ lệ mẫu 44.1kHz hoặc 48kHz, bitrate 128kbps - 192kbps).
- Quản trị viên cũng có thể tải nhạc trực tiếp qua giao diện Admin Dashboard > Quản lý nhạc nền.
